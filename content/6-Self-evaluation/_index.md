During my internship in the **First Cloud AI Journey (FCAJ) — Workforce Bootcamp** program, hosted by **Amazon Web Services Vietnam**, from **30/06/2026** to **14/08/2026**, I applied the knowledge from my Computer Science studies to a real cloud project and learned a great deal of new, practical material.

I worked on the **Court Booking application** — a hybrid AWS architecture combining a FastAPI monolith on EC2, an event-driven serverless payment path, Amazon RDS (PostgreSQL) as the single source of truth, and Amazon Cognito for identity. My main contributions were the **CI/CD and deployment track** (GitHub Actions, cross-account IAM/OIDC, EC2 + SSM Run Command, Amplify), the **backend API implementation** (FastAPI + SQLAlchemy + Alembic), and the **architecture design and documentation**. Through this work I strengthened my skills in cloud architecture, core AWS services (EC2, RDS, Cognito, VPC, IAM, Amplify, SSM), CI/CD pipelines, database design, deployment debugging, and technical writing.

In terms of work ethic, I aimed to complete every task to a high standard, followed the team's conventions, and communicated actively with teammates to keep the project moving.
